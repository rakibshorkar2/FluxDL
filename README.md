# FluxDL

**FluxDL** is a feature-rich, high-performance BitTorrent client for iOS written in Swift, powered by `LibTorrent-Swift` and `MVVMFoundation`.

## Features
- **Torrent Downloading & Management**: Download torrent files and magnet links effortlessly.
- **Bottom Navigation Bar**: Clean tab bar interface built with `UITabBarController`.
- **Background Downloads**: Support for background downloading session management.
- **LibTorrent Core**: Fast C++ libtorrent engine wrapped in Swift.
- **MVVM Architecture**: Modular, maintainable architecture powered by `MVVMFoundation`.

## Submodules
- `Submodules/LibTorrent-Swift`: Swift wrapper for libtorrent.
- `Submodules/MVVMFoundation`: MVVM framework foundation.

## Getting Started
Open `FluxDL.xcworkspace` in Xcode (requires Xcode 15+) and run the app on iOS 15.0+ or Simulator.
